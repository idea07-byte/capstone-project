## Run

```powershell
cd d:\java\capstone
javac -d out backend\Main.java backend\model\*.java backend\service\*.java backend\WebServer.java
java -cp out Main
```

- View available products
- Add a product
- Find a product by ID
- Remove a product by ID
- View users

- Find a user by ID
- Create a customer order with multiple items
- View order history
- Find an order by ID
